# study-workbench · 学生学习工作台生成器

> 一句话生成「学生每日学习工作台」单文件网页（HTML）：按进度排课、每日知识点+讲解+练习、每日积累、每日任务、单元测试复习、考试倒计时。支持按年级 / 学科 / 教材版本一键裂变。

## 触发词
`做个学习台` · `生成学生台` · `八年级上册语数英学习台` · `study workbench`

## 它能做什么
- **按进度排课**：以开学日为起点，在约 90 个上学日内把语数英三科均匀铺开；每天自动列出三科当天的知识点、讲解、练习题。
- **每日知识点 + 讲解 + 练习**：每课含完整课文/篇目与分析方法，练习题可逐题标记「已做」。
- **每日积累**：内置古诗文背诵全文（如《三峡》《答谢中书书》《孟子三章》《诗词五首》等）、数学公式、英语重点，按时轮转温故，可随时翻看积累库。
- **每日任务**：当日三科新课自动生成待办；昨天没学完的自动滚到今天并标红提醒。
- **单元复习**：学完一个单元即解锁「开始单元复习」，给出四步复习建议。
- **考试倒计时**：月考1 / 期中 / 月考2 / 期末四张卡片，日期与范围均可在「我的」里改。
- **本地存储**：数据存浏览器 localStorage，不依赖服务器；可导出 / 导入 JSON 备份，可导出 CSV 打卡记录。
- **零依赖零外链**：单文件 HTML，系统字体，内联 SVG，断网也能用；手机电脑通用，可「添加到主屏幕」当 APP。

## 模板裂变（换年级 / 学科 / 教材）
课程数据全部外置于一个 `CONTENT_PACK` 变量，引擎逻辑不写死任何课程内容：
1. 按 `references/content-pack-schema.md` 写一份新内容包 JSON（如七年级数学人教版、高一物理）；
2. 运行 `node references/inject_pack.js assets/study-workbench-engine.html 新包.json 输出.html`；
3. 引擎不变、内容换掉，立刻生成新学习台。

默认引擎已内置「八年级上册 · 语文/数学/英语 · 人教版（英语 2024 新版）」全套内容，开箱即用。

## 安装
- **ClawHub**：`clawhub install study-workbench`（或网页端搜索安装）
- **本地**：将本目录放入 `~/.workbuddy/skills/study-workbench/`，对话中说「做个学习台」即可触发

## 校验
- 语法校验通过；技能自带铁律静态检查 17/17；运行时六页渲染冒烟无错；
- 裂变注入后产物仍 17/17。

## 文件结构

```
├── icon.png                       # 技能图标
├── assets/
│   └── study-workbench-engine.html   # 引擎模板（默认已内置八上语数英人教版）

    ├── sample-pack-8up-cme.json   # 示例内容包（八上全套）
    └── inject_pack.js             # 裂变注入脚本
```
